# Quiz-App
A dynamic quiz application built with HTML, CSS, and JavaScript that fetches questions from a JSON file and tests your knowledge with a countdown timer.
# Features
- Questions loaded dynamically from a JSON file using `fetch()`
- Countdown timer for each question (30 seconds)
- Score tracking throughout the quiz
- Progress bullets showing current question position
- Results screen showing Good / Perfe
# Technologies Used
- HTML5
- CSS3 (Flexbox)
- JavaScript (DOM Manipulation, Fetch API)
- JSON
